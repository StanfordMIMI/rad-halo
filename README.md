# Rad-Halo

Code for the paper *Rad-Halo: An Expert-Annotated Benchmark for Detecting Hallucinations and Omissions in
LLM-Generated Radiology Impressions*.

Rad-Halo contains 300 MIMIC-IV radiology reports whose impressions were either kept from the original report
or generated by one of five LLMs. Radiology residents labeled every impression sentence as hallucinated or
supported and every relevant findings sentence as omitted or not; an attending radiologist adjudicated
disagreements. The paper analyzes annotator agreement, benchmarks LLM-as-judge detectors, and introduces
RadCheck 8B, a classifier trained on synthetic perturbations only.

The dataset is distributed through PhysioNet under credentialed access. This repository contains no report
text.

## What you can reproduce

| Level | Needs | Reproduces |
|---|---|---|
| **A. Analysis** | Rad-Halo from PhysioNet; CPU, ~1 min | Every number, table and figure in the paper's results |
| **B. Detection** | Rad-Halo; Vertex AI / Anthropic API keys or a GPU | The detector predictions in `predictions/` |
| **C. Construction and training** | MIMIC-IV-Note v2.2; Vertex AI, Anthropic; a GPU | Report selection, impression generation and MedVAL grading, prompt selection, synthetic training data, RadCheck training |

The annotation pipeline (Label Studio task preparation, aggregation, adjudication, release files) is in
[`annotation/`](annotation/README.md). It documents how the labels were produced; rerunning it requires the
private annotation exports.

## Setup

```bash
conda create -n radhalo python=3.12 && conda activate radhalo
pip install -e ".[dev]"            # level A
pip install -e ".[nlp,api]"        # + segmentation, Gemini and Claude (levels B and C)
pip install -e ".[local,vllm,train,medval]"   # + open-weights models, RadCheck training, MedVAL
pip install https://s3-us-west-2.amazonaws.com/ai2-s2-scispacy/releases/v0.5.4/en_core_sci_sm-0.5.4.tar.gz
cp .env.example .env               # paths and API credentials
```

Data (not included):
- **Rad-Halo** — download from PhysioNet and point `RADHALO_DATA` to the directory containing
  `rad_halo_dataset.json` (default `data/rad-halo/`).
- **MIMIC-IV-Note v2.2** (level C) — [physionet.org/content/mimic-iv-note/2.2](https://physionet.org/content/mimic-iv-note/2.2/);
  set `MIMIC_NOTE_DIR` to the directory containing `note/radiology.csv`.

MIMIC-derived data may only be processed with services that meet PhysioNet's requirements for credentialed
data (see [PhysioNet's guidance on LLM use](https://physionet.org/news/post/llm-responsible-use/)).

## A. Analysis

```bash
make analysis        # statistics, agreement, detector metrics, tables, figures
make test            # unit tests
```

Inputs are the PhysioNet release, the detector predictions in [`predictions/`](predictions/README.md) and
the small text-free files in [`derived/`](derived/README.md). Outputs go to `results/`; the committed copy
lets you check your run with `git diff results/`.

| Paper | Script (`scripts/analysis/`) | Output (`results/`) |
|---|---|---|
| Table 1, Sec. 5.1, Table 2 (error prevalence) | `dataset_statistics.py` | `csv/error_rates_*.csv`, `csv/modality_anatomy_counts.csv` |
| Sec. 5.1 risk trend (Cochran-Armitage) | `dataset_statistics.py` | `csv/risk_trend.csv` |
| App. B pre-highlighting, adjudication tables, per-annotator rates | `dataset_statistics.py` | `csv/prehighlight_coverage.csv`, `csv/adjudication_summary.csv`, `csv/adjudicator_agreement.csv`, `csv/annotator_error_rates.csv` |
| Table 3, agreement by source and risk level | `agreement.py` | `csv/agreement_*.csv` |
| Fig. 3, full detector metrics, Limitations self-evaluation check | `detector_metrics.py` | `csv/detector_metrics.csv`, `csv/judge_flags_by_source.csv` |
| All numbers quoted in the text and all result tables | `make_tables.py` | `values.tex`, `tables/*.tex` |
| Fig. 3, risk-grade distribution (App. A) | `make_figures.py` | `figures/*.pdf` |

Confidence intervals use a report-level bootstrap with 1,000 resamples (seed 0). RadCheck's threshold is
the F1-optimal threshold on the evaluated sentences, re-optimized in every bootstrap replicate.

## B. Detection

```bash
# LLM-as-judge; <judge> is a file in configs/judges/ (e.g. gemini-3-pro_low, claude-opus-4.5_16k, qwen3-8b)
python scripts/detection/run_llm_judge.py judge=<judge>

# RadCheck 8B (GPU)
python scripts/detection/run_radcheck.py --checkpoint <radcheck-checkpoint-dir> --out outputs/detection
```

Predictions are written as `outputs/detection/<detector>.jsonl` in the format of `predictions/`; judge runs
also keep the raw responses (`<judge>.raw.jsonl`) and resume where they stopped. The judge prompt is
`prompts/llm_judge.yaml`, the RadCheck input template `prompts/radcheck.txt`. Each configuration in the paper
was run once.

RadCheck 8B weights (LoRA adapter on Qwen3-Embedding-8B) are trained on MIMIC-derived data and are
therefore distributed with credentialed access through PhysioNet, not in this repository.

## C. Construction and training

All commands run from the repository root; `--help` lists the options.

**Eligible reports and segmentation** (Sec. 3.2, App. A.1–A.2)
```bash
python scripts/construction/preprocessing/01_filter_eligible.py --out data/mimic_eligible.jsonl
```

**Prompt selection** (App. A.4): sample 100 reports, generate with three instruction variants, compare
sentence counts.
```bash
python scripts/construction/impressions/01_sample_prompt_selection.py --eligible data/mimic_eligible.jsonl
python scripts/construction/impressions/02_generate_prompt_selection.py --generator <generator>
python scripts/construction/impressions/03_analyze_prompt_selection.py
```

**Impression generation and MedVAL grading** (Sec. 3.3–3.4, App. A.3, A.5–A.7)
```bash
python scripts/construction/impressions/04_generate_and_grade.py generator=<generator> random_seed=<seed>
```
`<generator>` is a file in `configs/generators/` (`reference` keeps the original impression). Rad-Halo used
`random_seed=101` for `gemini-2.5-flash`, `claude-sonnet-4.5` and `llama-3.1-8b` and `0` for the others.
The few-shot examples are MIMIC-IV-Note reports; the prompts contain placeholders that are filled from your
copy of MIMIC using the note ids in `derived/few_shot_note_ids.csv`. MedVAL (Aali et al., MIT licence) is
included in `src/radhalo/generation/medval.py`. `count_risk_grades.py` produces
`derived/risk_grade_counts.csv` from the generation logs.

**Synthetic training data** (Sec. 4.3, App. D)
```bash
python scripts/construction/preprocessing/02_preprocess.py --input data/mimic_eligible.jsonl \
    --out data/synthetic/pool.jsonl --holdout 1000 --split-seed 0 --num-rows 10000 --seed 0
python scripts/construction/synthetic/01_attribute.py --input data/synthetic/pool.jsonl \
    --out data/synthetic/attributed.jsonl --examples <physionet>/prompts/attribution_examples.yaml
python scripts/construction/synthetic/02_create_synthetic_data.py --input data/synthetic/attributed.jsonl \
    --out data/synthetic/radcheck_synthetic.jsonl
python scripts/construction/synthetic/03_composition.py --input data/synthetic/radcheck_synthetic.jsonl
```
The attribution prompt (`prompts/attribution.yaml`) contains three worked examples derived from MIMIC-IV
reports. Example 3 is rendered from your MIMIC copy (note id in `derived/few_shot_note_ids.csv`); examples 1
and 2 are not single MIMIC reports and are distributed with the Rad-Halo PhysioNet release
(`prompts/attribution_examples.yaml`).

**RadCheck training** (Sec. 4.2, App. C.4; one A100 40GB)
```bash
python scripts/construction/training/train_radcheck.py dataset.input_file=data/synthetic/radcheck_synthetic.jsonl
```
Hyperparameters are in `configs/train_radcheck.yaml`. Weights & Biases logging is off by default
(`wandb.enabled=true` to enable).

## Repository layout

```
src/radhalo/       library: data loading and segmentation, LLM backends, detection, generation,
                   synthetic data, training, evaluation, LaTeX/figure output
scripts/           analysis/ (level A), detection/ (level B), construction/ (level C)
configs/           judge, generator, generation, detection and training configs (Hydra)
prompts/           prompt templates (no MIMIC text)
predictions/       detector outputs on Rad-Halo (scores only)
derived/           text-free inputs derived from restricted data
results/           analysis outputs used in the paper
annotation/        annotation pipeline and PhysioNet release builder
tools/             leak check run in pre-commit and CI
```
